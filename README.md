# Simple Doodle Jump

A C++ implementation of the classic *Doodle Jump* game, built with the SFML library and developed across two progressive phases — from core platforming mechanics to a fuller game with enemies, combat, and sound.

## Phases

- **[Phase 1](./phase1)** — The initial version of the game: basic platforms, jumping mechanics, and score tracking.
- **[Phase 2](./phase2)** — The extended version: enemies, shooting, sound effects, configurable settings, and more.

## Tech Stack

- **Language:** C++
- **Graphics/Audio:** [SFML](https://www.sfml-dev.org/)
- **Build system:** Makefile (Windows via MSYS2/MinGW-w64, or Linux/macOS)

## Getting Started

Each phase is a self-contained project with its own build instructions, project structure, and architecture notes. See the README inside [`phase1`](./phase1) or [`phase2`](./phase2) for details on how to build and run it.
